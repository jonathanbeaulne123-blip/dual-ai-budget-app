# Hearth worksession

1. Read `AGENTS.md`, `docs/AI_OPERATING_MODEL.md`, `docs/STRATEGY.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`, and `docs/AI_HANDOFF.md`.
2. Establish the exact repository, branch, HEAD SHA, working-tree state, and relevant PR or issue.
3. State what is verified and what remains inferred.
4. Assign Low, Medium, Medium-High, High, or Release risk.
5. Name the Budget delta (weight 5) and Engagement delta (weight 3).
6. Define the household outcome, scope, non-scope, acceptance evidence, and decision owner.
7. For Medium/Medium-High/High/Release work, create or update `docs/worksessions/YYYY-MM-DD-<short-slug>.md` from `docs/worksessions/TEMPLATE.md`, using the Toronto calendar date.
8. Delegate only independent bounded investigation. Keep one writer per checkout.
9. Before closing, record changed files, exact commands and results, unresolved risks, links, and the next owner.

Do not treat chat memory, an artifact, a preview, or an unmerged PR as `main`. Do not load museum folders unless historical research is explicitly required.
