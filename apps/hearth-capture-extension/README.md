# Hearth 7shifts Capture companion

Development-only Manifest V3 companion. Capture starts only from the popup while the active top-level page is `https://app.7shifts.com`. It reads same-origin response copies and an explicitly selected visible screenshot. It has no cookie, webRequest, history, downloads, clipboard, or all-sites permission and never reads request headers or form passwords.

Captured values remain in extension session storage until a signed-in Hearth page pairs a one-time upload capability. No store distribution, hosted pairing, or activation is included in this local packet.
