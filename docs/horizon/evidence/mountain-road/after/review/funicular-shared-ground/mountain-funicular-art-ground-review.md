# Local funicular art / ground ownership review

Bounded source and saved-data review only. No source imports, world construction, browser, tests or checkout changes. Sources reviewed are the frozen v12 geometry layer and `/tmp/mountain-funicular-art-local/source`; this is not a verdict on the still-running v16 candidate.

**P1 remains: the local repair has different rendered and physical ground.** `regions/mountainV2/ground.ts:32–34` builds a tier-specific lattice and then caps it. `geometry/capGroundMesh.ts:24` lowers all three original terrain vertices when any overlap is too high; this changes the rest of those triangles and every incident triangle. In contrast, `regions/mountainV2/geography.ts:217–224` continues to query the analytic `min(groundHeightAt, groundCeiling)` at each point. The local path renderer correctly selects its actual prepared ground triangles (`funicularFootPath.ts:64`) and offsets its paint 40–50mm from those faces (`:107–109`). That therefore cannot also be 40–50mm above the different physical floor.

The saved `/tmp/mountain-funicular-art-local-proof/results.json` has 498 full and 402 lite terrain-owned clearance failures. The most negative terrain-only gaps are:

This is independent of the candidate's rejected skinny-triangle problem and does not disappear by preserving distant path primitives. Raising the paint to the queried height alone would leave the terrain drawing and support different. A full-tier lattice query alone also leaves lite wrong; a tier-specific physics query changes the shared world with quality settings.

The native path extraction/selection is otherwise bounded and sound on reviewed evidence. `mountain/art/routeArt.ts:139–154` retains the original frames, hashes, width profile, colors, box transforms and tier spacing. The default route still takes the original whole-sweep call. `/tmp/mountain-funicular-art-parity-all/parity.json` records all 228 default/selected primitive comparisons exact. Local proof retains 56/44 full/lite ribbon triangles and 5/2 verge stones, with `preservedChanged=0`; no additional selection regression was found.

## Smallest coherent correction

Keep one **tier-independent local ground collar** as the authority. Its exact triangles must be shared by full/lite drawing, local physical ground/surface normals and the path-art host list. Keep this wholly in the Horizon placement layer; outside its explicit plan polygon, use the unchanged native behavior.

Prefer a real Horizon `StructureSolid` collar if the native lawn paint/material can be retained. The current static solid path already gives the two render tiers and collision the same physical triangles; a thin real earth/stone shell can seal its edge. Otherwise use a shared local prepared mesh plus one exact triangle sampler—both tiers must physically draw that same mesh. In either version, the surface is explicit geometry, not an extra mathematical support function under a different drawing.

The collar should include the union of the measured ground impact in both tiers, with its outer boundary fitted to the unchanged analytic native floor. It must then pass the actual outer-boundary movement/grade and rendered-seam checks in both tiers. Do not silently choose a larger area or assume a coarse tier's old edge height is identical to the full tier. Rejected v12's art repair bounds were approximately [1283,716.2783]–[1296.75,736.3130] full and [1282,716]–[1298,736] lite; these are evidence of that rejected attempt, **not final authorized collar dimensions**. Use the final candidate's fresh impact inventory.

Remove only the funicular whole-vertex cap from the original lattice path. Clip the already-painted native ground triangles against the collar's exact plan boundary at final geometry assembly, then insert the shared collar. Do not change `Lattice.cols/rows/xs/zs` or append vertices before `groundMasks`: the global per-tier masks assume the original lattice structure. When clipping creates new final render vertices, interpolate the existing color/UV attributes; keep the original lattice and mask arrays intact. Keep any skirt vertical or downward-facing and out of top-floor selection. Native road/plank surfaces still win as the highest supported drawn floors, and the new collar must not cover their protected footprint.

Wire the common collar membership into the already-proposed streaming invalidation. Its late arrival must refresh the exact query, dispose stale ground/path art and clear region ground caches together. The streaming diagnostic currently expects the v12-style single ground mesh; if the selected implementation uses a separate collar mesh, revise its explicit rendered-mesh inventory and cap sampling before running it. Do not count a missing new mesh as an unchanged successful proof.

**P2: isolate Horizon ground-mask caching as well.** `src/harbour/scene/groundPaint.ts` currently caches `groundMasks` by tier only, disregarding the lattice and height callback. A fresh region `PreparedGround` cache therefore does not ensure fresh shading masks after a join arrives; a prior native/Horizon generation can supply the wrong slope, cavity and sun fields. Add an optional fourth mask-cache argument defaulting to the existing native `maskCache`, and use that argument for both get/set. Horizon `prepareRegionGround` supplies its own cache (or a fresh map when producing a new PreparedGround); native callers omit it and retain exactly the old default. Do not mutate the original lattice shape, or reuse a mask array for a new collar vertex layout. The local collar can sample privately computed native paint into its own final attributes.

Required bounded validation: exact same local top positions/indices and queried normals in both tiers; source/native byte preservation; complete full-width and exposed-boundary sweeps; the two ordinary paths both directions; no terrain or slab proud of the collar; no retained path art outside the new impact area changed; all existing 35–60mm art clearance limits unchanged; final Float32/served-mesh checks; delayed chunk/scene lifecycle; both-tier captures. The source review establishes the required correction, not a verified collar design.

## Separate diagnostic edge witnesses

The largest reported slab gaps have a different cause and must remain separately attributed. The existing runtime `geography.ts:34` expands triangle barycentric membership by `1e-6`; art clipping uses the exact plan polygons. Pure saved-JSON arithmetic found all 212 full and 200 lite `threshold.funicular.town.to.hearth.slab@lakeside` witnesses outside its exact top polygon but inside that existing query tolerance. For example z=725.5999996 is 0.4 micrometres outside the slab's exact z-min725.6. All six full and six lite apron-owned witnesses likewise have no exact top hit and only the expanded-tolerance hit. These are not evidence of paint geometrically hidden beneath an overlapping drawn slab. They remain actual query discrepancies, distinct from the centimetre-scale terrain mismatch above.

Do not globally alter runtime barycentric tolerances, broaden the physical slab or relax the paint gap test to hide these. Retain the raw surface-query failure and report an exact drawn-owner intersection alongside it; after the ground repair, any remaining discrepancy needs that explicit disposition. A narrow exact-owner visual-art assertion can coexist with the original physical-query diagnostic, but should not relabel its raw failure a pass.
