## Patch scope and invariants

Only `src/journey/land/road.ts`, `src/journey/land/bridges.ts`, and `test/journey-road.test.ts` change.

`planBridges` keeps every full axis, arc length, width, compressed top, carried line and underpass relationship. It adds a draw-index list generated by a deterministic plan/profile simplifier. Only the visible shadow/deck/side/rail strips consume these indices. Each retained cross-section uses the original source frame and original width; no fitted vertex replaces its XYZ. Endpoints and forward source-index order are exact. Piers still consume the full plan/arc/top arrays and stand at precisely the previous positions.

The data model, extractor, saved Journey axes, flat-twin axes, native export, native physical meshes and Horizon physical meshes remain unchanged. Existing cast names/glyphs/landmarks and all3 native identities/widths remain. Covered/underpass decisions, road draping and bridge-near refinement still read the full axes. No budgets/tolerances for gameplay or tests are raised.

The simplifier checks lateral distance and raw height error at every source point against its enclosing retained chord. It also rejects reversal in chord projection. Projections are ordered within[0,1]; interpolation on each original source segment therefore keeps the same error bounds between sample points. The error bound is on centreline plan/profile; retained section frames and widths are exact, but this is not a separate15cm Hausdorff proof of every rail/miter corner. All current bridge heights remain on one side of the map compression knee20m, so height compression is linear across each source bridge.
