No esbuild, fixture, source fit, or checkout write. Imports only the prior served preflight's frozen runtime bundle, whose hash must match the recorded report. World, terrain, native data and proof hashes are retained and checked for drift. The baseline uses the actual served collision metadata; the unrounded production prejoin fixture is intentionally not substituted for runtime metadata.

Old full/lite ground is each prepared once. Local exact unchanged tier triangles within core+1.5m are saved with original vertex/face identities, plus 0.1m analytical physical/old-render samples. Seven candidate outer rectangles (0 through1.5m at0.25m) are sampled at no more than2cm intervals. Published nativePlanning path ribbons crossing the footprint get0.1m along /0.2m across samples plus exact source edges, body-safe centers and0.3m exterior points. These are source-metadata probes, not controller acceptance.

Read summary.json first, then the compressed raw JSONs for any witnesses. A zero exit code means measurement completed without drift, not that a collar is approved or any threshold passed. No proposed collar mesh is generated.
