# Rejected exact planar funicular reduction

The 16,036 to 6,704 triangle reduction preserves the tested apron surface to arithmetic precision, but the actual canonical ground construction changes by up to 0.2589212656 m. The October 1 root parity-only run exited 2 before movement and artwork. Coverage and indices were equal; ground positions were not. This fails the 1 micrometre parity bound.

The reducer and its production call were removed before the draft PR. Its implementation, focused test and failing actual-served proof are preserved in evidence.tar.gz. The unreduced 16,036 triangle apron remains the source and asset authority. No rendering budget exception is implied.
