# Other Foot reduction probes — not adopted

A separate saved-mesh probe tests the main Foot apron and clipped S1/Year Walk fragments using origin zero, reproducing their actual default absolute-coordinate render path. Unlike the funicular source, several inputs already contain tiny positive tops, Float32 collapse/inversion, or overlapping geometry. Year Walk bed has 12 oriented-edge failures; the shoulder overlap prevents the strict one-cover common-refinement proof. The candidate reduction does not resolve those issues and remains rejected. Three small fragments numerically pass but together save only 116 faces; none is applied.

This distinct probe allows inherited runtime-invisible positive source faces to be considered for exact removal, records them, and still requires zero such failures in every final numerical audit. It changes no production threshold. No native or runtime geometry is modified by these studies.
