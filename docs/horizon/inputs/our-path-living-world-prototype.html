LIVING WORLD LAB / 01

The world is a projection.
Never another ledger.

This original, offline prototype uses synthetic events and a mocked coverage adapter. It does not connect to Hearth, inspect your accounts, post money, or change the repository.

Implemented: deterministic multi-centre terrain; six synthetic history profiles; a six-category growth subset; backing stages; localized material wear; eroded geometry; recovery on the same sites; incomplete-evidence freeze; error-correction replay; clickable explanations and a text inspector.

accepted, scope-safe facts
  → trusted daily coverage
  → deterministic world rules
  → bounded scene geometry
  → renderer + explanations

Calibration: stage gates start at 3 / 7 / 14 / 28 confirmed days, with severity or material-arrear-age checks. Clearance is below 0.25 × daily need with no material arrears. Repairs start after two clear days. These are proposed product settings, not financial advice.

Still illustrative: the terrain deformation maps a bounded wear signal into a visible gully; it does not yet enforce the rulebook's exact eroded-area budget or every weekly place cap. Six profiles are authored fixtures, not proof of a production history adapter or infinite uniqueness. Plants and structures are stylized procedural models, not final Hearth artwork.

No external libraries, fonts, models, CDN, API key, tracking, or runtime network requests. Real iPhone performance and production integration still need validation. The source kit includes the pure rules, renderer, tests, and adapter notes.
