## Widget caller seam

`captureNativeWidget({designId, revision, piece}, AbortSignal)` renders the exact `snapshotKittyDesignRevision` piece once to PNG at fixed authored scale. No backing/goal/animation input is accepted. The renderer and sculpture are disposed even on cancellation or failure. A WebGL failure is visible; no alternate sculpture is substituted.

`NativeWidgetSurface` accepts `{controller, plugin, scope, selection, onClose}`. Obtain controller/plugin from `nativeWidgetController()` / `nativeWidgetPlugin()` after native hydration. Capture on a deliberate Studio action, cancel its AbortController on scope change/unmount, then show this surface. Browser builds have null controller/plugin and should omit the native widget action. Parent's Studio owns the selected immutable revision and theme context; pass the exact selection only. Do not automatically publish the preview.

The surface reviews exact PNG bytes and immutable identity, warns that painted writing remains visible, requires an unchecked opt-in checkbox, and offers Save/Remove/Return. A changed image/revision/scope invalidates review. Saved platform data is a re-encoded PNG, random selection ID, scope digest and format version: no title, member/household name, balance, target, contribution history, bearer or financial scale. The default is simply “Hearth.” Tapping the widget opens the app via `hearthside://open/widget`, with no private identity in the link. Existing app authentication still controls access; it never creates an authenticated route capability.

Android: library manifest includes the AppWidgetProvider and RemoteViews resources, merged during Capacitor sync. Users deliberately add the widget using their launcher after saving. No automatic pin is performed.

iOS: `native/widgets/ios` includes actual WidgetKit provider/view, Info.plist, entitlements and an optional XcodeGen extension target definition. Add/embed the extension in the host project, configure the **same reviewed App Group** on the host and extension, and set `HearthsideWidgetAppGroup` in each Info.plist. Add the App Group entitlement to the host as well. No team, group or provisioning is invented by this package. Until configured, iOS reports widget unavailable. The shared group never receives Keychain credentials. Signing/configuring distribution remains a Release action.

## Durability and identity

- One secure atomic record per environment holds `{version, environment, issuer, session}`; a null session is a durable tombstone. Hydration validates all fields, JWT issuer/subject/session ID/email/Google subject/expiry consistency and exact environment. JWT decoding is a consistency check on the authenticated TLS token response, not cryptographic verification or household authorization.
- Pending PKCE state contains one random verifier, random callback nonce, ten-minute deadline, environment, HTTPS issuer, expected existing account, exact local return path, callback and exchange phase. The verifier is never put in the authorize URL. Supabase uses `code_challenge_method=s256` and `/auth/v1/token?grant_type=pkce` with `auth_code`/`code_verifier`.
- Callbacks reject alternate schemes/hosts/path/port/userinfo, fragments, bearer tokens, duplicate/unknown parameters, wrong nonce and environment. No callback determines a household membership.
- Received tokens are securely checkpointed before the session write. Restart after a session-write failure resumes without exchanging the consumed code again. Callbacks are acknowledged only after secure session durability. Pending credentials are removed after completion. If the network lost the only token response, retry may require a new Google sign-in; no success is manufactured.
- One flow at a time; same-account reauthentication rejects another user unless Switch account is explicit. Cancellation invalidates in-flight work synchronously, writes a secure tombstone, then clears the native callback/state. A cancellation or widget-clear failure is not reported as sign-out success. Later network replies cannot revive it. Ordinary Auth does not depend on camera or AR support.
- The native-origin old plaintext Supabase/Google/gcal token keys are discarded; they are never imported. Direct Google-suite connectors retain only transient memory credentials natively and still require their separate explicit connection/disclosure gates. Web storage behavior is unchanged.
