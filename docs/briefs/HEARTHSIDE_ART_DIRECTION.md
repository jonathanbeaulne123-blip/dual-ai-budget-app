# Hearthside authored worlds

Status: implementation brief, not acceptance evidence. Program baseline: `429db8e`.

Jonathan's approved P0–P15 scope is authoritative. Claude Desktop's **Hearthside design second opinion** was consulted on 2026-09-12 for composition and assets. The following is the integration owner's selection from that advice, with product constraints applied.

## A visible intention through the house

Actual authored objects carry state: the Studio shelf shows chosen pieces, the common-room note rail holds shared notes, and the Theatre holds the couple's kept compositions. A focused intention can draw a linen cord, grosgrain ribbon, or mooring line through its linked objects. The line never invents a bank, activity, recollection, or relationship milestone. Empty rooms are finished compositions with an invitation to do something free.

Use six named depth layers: sky, far architecture, thresholds, furniture, semantic objects, foreground/light. Semantic coordinates persist; each theme interprets materials and furniture silhouettes. Phone layouts present close crops plus the complete semantic object index. All actions are native HTML controls, with 44px targets and labels on readable surfaces. Illustrated and reduced-motion modes retain every action. No attention, money or relationship metric controls ambient beauty.

## Advice deliberately declined

- No reduction to one complete theme with two palette reskins; all twelve room compositions remain required.
- Wardrobe and portraits remain in scope alongside pottery and paired reveals.
- Presence lights require opted-in, authenticated presence. The room never implies a partner is present without it.
- No shared timer, forced simultaneous hold, or mandatory partner gesture blocks an individual's authored work. Review consent uses explicit versioned controls, with keyboard equivalents.
- No read receipts, dampening of unread notes, guilt-based wish growth, lost shadows for absence, or financial activity requirement.
- Private answer reveals use the Vault. A visually folded shared note is still shared and is labelled accordingly.
- Changes to shared financial meaning retain existing Final Confirm and mutual acknowledgement rules. An intention itself does not require manufacturing a financial agreement.

The consultation is design input, not independent implementation approval. Visual, physical-device, authenticated collaboration, performance and accessibility evidence remains outstanding.
