**Why-notes (docs rebuild, 2026-08-22)**

- **D-022** still says seed data includes chequing, Visa, and cash. That is the original defect name (hidden first-active-account). Catalog kinds are D-047; `cash` migrates to `other`. We did not rewrite the seed sentence so the bug D-022 prevents stays searchable.
- **Rings and Chapters** are not deleted as *ideas*. They are retired as *indexes of the future*. Shipped rituals (chalkboard, cook-off, sit-down postcard, spectacles, wallet tiles) remain product.
- **Charter “out of scope until the core is boring”** is replaced by unbounded Dual Course vision plus engineering gates. Why: the core is already a general ledger; pretending bank rails are unthinkable was how the old maps went stale, and pretending they are next-week work was how they got dangerous. Auth + RLS still comes first.
- **D-033** still says the hosted schema is the same as PGlite. That remains true of the SQL file. The app currently writes hosted `households` + `household_snapshots` (JSON). It does not populate hosted `journal_*` tables. PGlite is the books engine (D-052).
- **D-034** still says the publishable key is not a privacy boundary. Spell out the current door: `FOR ALL … USING (true) WITH CHECK (true)` includes DELETE. A caller who has the bundled key can read and empty hosted snapshots without the three-word phrase. Treat published hosted rows as disclosed until Auth (D-052).
- **D-047** still lists chequing / savings / credit / investment / other. Receivable (D-053) is a sixth kind: money owed to us. We did not rewrite D-047's sentence so the Accounts Floor's original object list stays searchable. `other` remains the jar.
- **D-053 / D-054 / D-055** (2026-08-22): Jonathan fixed receivable-then-settle and granted full authority including amending canon. Quiet labels and propose-only jars are Cursor's designs, recorded here so the next agent does not treat them as undecided. Snapshot hash now includes claim amounts (D-052 spirit). METC projection is out-of-pocket after expected recovery — pending Sun Life does not inflate the credit.
