# The Queen's world — 3D port evidence

Captured on branch `claude/queen-world` from `origin/main@2f5e9c5` (#470, the Still Queen) with `node test/queen-world-layout.mjs` (Chromium with `--use-gl=angle --use-angle=swiftshader` for the WebGL sections and `--disable-3d-apis --disable-gpu` for the no-WebGL section). Every household is fictional: `planLifeFixture("household")` renamed "Fictional household", members "Alex (fictional)" and "Sam (fictional)". No real books, no hosted rows.

`records.json` holds 28 records. The 3D path (`world=3d`, `reducedMotion: reduce`): five pulse seeds at rest at 390 and 1100 and `building` at all five viewports with the App's chrome stand-ins — one canvas covering the field, the same rest inventory (Together · her · Move · Status) over it, the drawn figure and the DOM breath yielding to the sculpture, no frames rendered while nothing changes, the 3D still in words; the expand with Protect, Build and a goal bank placed as studio sculptures on their DOM seats; the Protect peek and the cellar (the field fades, she does not follow); keyboard order and a 3px ring over the canvas; offline matte. Motion (`no-preference`): she breathes at rest and stops when expanded, with no frames while still. The flat path (`world=flat`) at all five viewports: no canvas, the drawn figure, the banks as the studio's flat twins with fired read from the piece. A browser with no WebGL (`world=auto`): the host tries, yields silently, no note, the flat reading intact.

Measured everywhere: 0 horizontal overflow, 0 vertical page scroll, 0 serious/critical axe hits, 0 page errors. Frame timings are from SwiftShader (CPU rendering) in the cloud container, not a phone: steady-state frames 1–6 ms, first frames 280–420 ms (shader compilation), the expand's first frame 155–217 ms (three new sculptures compiled at once); a mid-range phone was not available to measure.

The PNGs here are a curated subset; regenerate the full set with `HEARTH_ARTIFACTS_DIR=.artifacts/queen-world node test/queen-world-layout.mjs` (set `HEARTH_CHROMIUM` when the Playwright browser cache is older than the package expects).
