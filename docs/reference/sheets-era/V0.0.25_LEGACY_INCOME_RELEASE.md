## Safety design

`Maintenance.gs` adds two v0.0.25 development-only menu actions:

1. **Preview v0.0.25 Income-ID Corrections** — read-only. It requires exactly one row for each of the 14 stable transaction IDs, requires the spreadsheet timezone already be `America/Toronto`, validates the direct current values, and checks every derived cell's formula and current result.
2. **Apply v0.0.25 Income-ID Corrections** — requires the exact phrase `APPLY V0.0.25 TO DEV`, rebuilds and fingerprints the plan under a document lock, writes only pending direct Q cells, flushes, then verifies all direct values and all untouched S formulas/results. On failure it attempts a reverse-order rollback of its direct writes.

The controls appear only when `APP_VERSION` is exactly `v0.0.25` and the active spreadsheet name exactly matches the development Sheet. The completed v0.0.24 controls are hidden on v0.0.25.

After a successful correction, the tool refreshes Budget/Dashboard/Income History, reruns Data Health Check, and adds one Change Log entry. It does not enable scheduled refresh.
