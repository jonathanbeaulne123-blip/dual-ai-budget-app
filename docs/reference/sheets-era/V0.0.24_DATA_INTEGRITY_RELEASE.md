## Safety design

`Maintenance.gs` provides two development-only menu actions:

1. **Preview v0.0.24 Data Corrections** — read-only. It requires exactly one row for every stable ID, checks the real row-4 headers, and accepts only the verified old value or intended final value.
2. **Apply v0.0.24 Data Corrections** — requires the exact confirmation phrase `APPLY V0.0.24 TO DEV`, rebuilds the plan under a document lock, compares it with the confirmed preview, writes only pending items, verifies all 13 final values and the timezone, and attempts to roll back its own writes if anything fails.

The actions appear only when the active spreadsheet name is exactly `devCopy of Budget_App__v 0.23`. `APP_VERSION` must also be exactly `v0.0.24`.

After a successful migration, the tool refreshes the Budget/Dashboard/Income History summaries, reruns Data Health Check, and records one Change Log entry. It does not enable the scheduled refresh.
